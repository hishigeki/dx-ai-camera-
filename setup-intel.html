A
公式 Python をインストールする
Microsoftストア版ではなく、公式サイトからダウンロードします

ブラウザで以下の URL を開いてダウンロードしてください。

URL 
https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe
⚠️
インストール時に必ずチェック！

インストール画面の一番下にある
"Add Python 3.11 to PATH" にチェックを入れてから「Install Now」をクリック！
これを忘れると Python が正しく動きません。

  • ダウンロードしてインストーラーを実行した
  • "Add Python 3.11 to PATH" にチェックを入れた
  • 「Install Now」でインストール完了した
B
VS Code をインストールする
コードを書くためのエディタです

ブラウザで以下の URL を開いてダウンロードしてください。

URL 
https://code.visualstudio.com/
💡
インストール後にやること

VS Code を起動 → 左サイドバーの拡張機能アイコン（四角が4つ）→ 検索バーに Python と入力 → Microsoft 製の「Python」をインストール

📁
作業フォルダを作ろう

デスクトップに ai_camera というフォルダを作成 → VS Code で「ファイル」→「フォルダーを開く」→ ai_camera を選択

  • VS Code をインストールした
  • Python 拡張機能をインストールした
  • ai_camera フォルダを作って VS Code で開いた
  • VS Code を一度閉じて開き直した（Pythonを認識させるため）
✅
セットアップ完了！

Intel CPU のセットアップはこれで終わりです。次のページから演習を始めましょう。
