カメラを起動してリアルタイム映像を表示しよう
camera_ai.py に貼り付けて ▶ または F5 で実行
✏️ 演習①

パソコンにはカメラが複数ある場合があります。どのカメラを使うか番号で指定します。
内蔵カメラは 0、外付け USB カメラは 1 です。

camera_ai.py 
import cv2

# ── 演習①：カメラの番号を指定 ──
# 内蔵カメラ = 0   USBカメラ = 1
cap = cv2.VideoCapture( □□ )

if not cap.isOpened():
    print("エラー：カメラが見つかりません")
    exit()

# ループでリアルタイム映像を表示
while True:
    ret, frame = cap.read()
    if not ret: break
    cv2.imshow("Step2: Camera", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break

cap.release()
cv2.destroyAllWindows()

camera_ai.py（上書き） 
import cv2
from ultralytics import YOLO

# ── 演習②：AIモデルの名前を指定 ──
model = YOLO( '□□□□□□□□□□' )

cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()
    if not ret: break
    results = model(frame, verbose=False)
    names = [model.names[int(b.cls[0])]
             for r in results for b in r.boxes]
    label = 'Found: ' + ', '.join(names) if names else 'Found: nothing'
    cv2.putText(frame, label, (10,40),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255,255,0), 2)
    cv2.imshow("Step3: AI Detection", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break

cap.release()
cv2.destroyAllWindows()

✏️ 演習③

枠の色を RGB で指定します。OpenCV は BGR（青・緑・赤）の順番なので注意！

緑
(0, 255, 0)
赤
(0, 0, 255)
青
(255, 0, 0)
黄
(0, 255, 255)
紫
(255, 0, 255)
camera_ai.py（上書き） 
import cv2
from ultralytics import YOLO

model = YOLO('yolov8n.pt')
cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()
    if not ret: break
    results = model(frame, verbose=False)
    for r in results:
        for box in r.boxes:
            x1,y1,x2,y2 = map(int, box.xyxy[0])
            name = model.names[int(box.cls[0])]
            # ── 演習③：枠の色を (B,G,R) で指定 ──
            # 例：緑=(0,255,0)  赤=(0,0,255)
            color = ( □□□, □□□, □□□ )
            cv2.rectangle(frame,(x1,y1),(x2,y2),color,2)
            cv2.putText(frame,name,(x1,y1-10),
                        cv2.FONT_HERSHEY_SIMPLEX,0.6,color,2)
    cv2.imshow("Step4: Bounding Box",frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break

cap.release()
cv2.destroyAllWindows()

5
信頼度のしきい値を設定しよう
camera_ai.py に丸ごと上書きして実行
✏️ 演習④

AI が「これは〇〇だ！」と判断するとき、どのくらい確信していたら表示するかを 0〜1 の数値で設定します。

conf = 0.9
90%確信 → 厳選（少ない）
conf = 0.5
50%確信 → バランスよい ★推奨
conf = 0.1
10%確信 → なんでも検出
camera_ai.py（上書き） 
import cv2
from ultralytics import YOLO

model = YOLO('yolov8n.pt')
cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()
    if not ret: break
    # ── 演習④：信頼度のしきい値を指定 ──
    # 0.3→多め  0.5→バランス  0.8→厳選
    results = model(frame, conf=□.□, verbose=False)
    count = 0
    for r in results:
        for box in r.boxes:
            x1,y1,x2,y2 = map(int,box.xyxy[0])
            name = model.names[int(box.cls[0])]
            conf_v = float(box.conf[0])
            cv2.rectangle(frame,(x1,y1),(x2,y2),(0,255,0),2)
            cv2.putText(frame,f'{name} {conf_v:.2f}',(x1,y1-10),
                        cv2.FONT_HERSHEY_SIMPLEX,0.6,(0,255,0),2)
            count += 1
    cv2.putText(frame,f'Count:{count}',(10,40),
                cv2.FONT_HERSHEY_SIMPLEX,1.0,(0,255,255),2)
    cv2.imshow("Step5: Confidence",frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break

cap.release()
cv2.destroyAllWindows()
答え例 
results = model(frame, conf=0.5, verbose=False)
# 0.5 = 50%以上確信したものだけ表示（推奨）
確認：画面左上に "Count:X" が表示され、conf 値を変えると数が変わる

camera_ai.py（完成版） 
import cv2
from ultralytics import YOLO

# ① AIモデル読み込み（演習②で決めた）
model = YOLO('yolov8n.pt')

# ② カメラ指定（演習①で決めた番号）
cap = cv2.VideoCapture(0)

if not cap.isOpened():
    print("エラー：カメラを開けませんでした")
    exit()

print("AI カメラ起動！ 'q' キーで終了")

while True:
    ret, frame = cap.read()
    if not ret: break

    # ③ AI検出（演習④で決めた conf 値）
    results = model(frame, conf=0.5, verbose=False)

    for r in results:
        for box in r.boxes:
            x1,y1,x2,y2 = map(int,box.xyxy[0])
            name = model.names[int(box.cls[0])]
            confidence = float(box.conf[0])

            # ④ 枠の色（演習③で決めた BGR 値）
            color = (0, 255, 0)

            cv2.rectangle(frame,(x1,y1),(x2,y2),color,2)
            cv2.putText(frame,f'{name} {confidence:.2f}',
                        (x1,y1-10),cv2.FONT_HERSHEY_SIMPLEX,
                        0.6,color,2)

    cv2.imshow('AI Object Detection', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break

cap.release()
cv2.destroyAllWindows()
print("終了しました")
