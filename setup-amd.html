⚠️
AMD CPU で起きやすい問題

AMD CPU では PyTorch（AI ライブラリ）が必要とする c10.dll の初期化に失敗することがあります。Visual C++ ランタイムを先にインストールすることで解決できます。

A
Visual C++ ランタイムをインストールする
AMD CPU では必須の追加作業です

ブラウザで以下の URL を開いてダウンロード・実行してください。

URL 
https://aka.ms/vs/17/release/vc_redist.x64.exe
🔄
インストール後は必ず再起動！

インストールが完了したら、パソコンを再起動してください。再起動しないと効果が出ません。

  • vc_redist.x64.exe をダウンロードして実行した
  • インストールが完了した
  • パソコンを再起動した
B
公式 Python をインストールする
Microsoftストア版ではなく、公式サイトからダウンロードします

ブラウザで以下の URL を開いてダウンロードしてください。

URL 
https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe
⚠️
インストール時に必ずチェック！

インストール画面の一番下にある
"Add Python 3.11 to PATH" にチェックを入れてから「Install Now」をクリック！
これを忘れると Python が正しく動きません。

  • ダウンロードしてインストーラーを実行した
  • "Add Python 3.11 to PATH" にチェックを入れた
  • 「Install Now」でインストール完了した
C
VS Code をインストールする
コードを書くためのエディタです
URL 
https://code.visualstudio.com/
💡
インストール後にやること

VS Code を起動 → 拡張機能アイコン → 検索バーに Python → Microsoft 製をインストール
デスクトップに ai_camera フォルダを作成 → VS Code で開く

  • VS Code をインストールした
  • Python 拡張機能をインストールした
  • ai_camera フォルダを作って VS Code で開いた
  • VS Code を一度閉じて開き直した
✅
セットアップ完了！
