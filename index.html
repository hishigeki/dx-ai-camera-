自分の CPU の確認方法がわからない場合
  1. キーボードの Windows キー + R を押す
  2. dxdiag と入力して Enter
  3. 「プロセッサ」の欄に Intel または AMD と表示されます

または、タスクバーを右クリック →「タスクマネージャー」→「パフォーマンス」→「CPU」でも確認できます。
